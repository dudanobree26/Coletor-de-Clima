# Coletor de Dados Climáticos — API Open-Meteo

## Sobre o Projeto
Projeto desenvolvido em Python que coleta dados climáticos
reais dos últimos 7 dias via API Open-Meteo e salva em CSV.

## O que o projeto faz
- Recebe latitude e longitude do usuário
- Conecta com a API Open-Meteo (gratuita)
- Coleta temperatura máxima e precipitação diária
- Converte temperatura de Celsius para Fahrenheit
- Salva os dados em arquivo CSV

## Ferramentas Utilizadas
- **Python**
- **Requests** requisição HTTP para a API
- **Pandas** manipulação e exportação dos dados
